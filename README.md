# ☕ Sweet Coffee Landing Page

A modern and responsive coffee shop landing page designed to showcase coffee products, customer experiences, and brand identity through an engaging and visually appealing user interface.

## 🌟 Overview

Sweet Coffee is a frontend web project created to deliver an immersive coffee shop experience online. The landing page highlights featured coffee products, manufacturing processes, customer testimonials, business hours, and location information while maintaining a clean and modern design.

## ✨ Features

- Responsive and mobile-friendly design
- Modern coffee-themed user interface
- Hero section with call-to-action
- Featured coffee products showcase
- Coffee manufacturing process section
- Customer testimonials
- Opening hours display
- Embedded location map
- Professional footer section
- Smooth and organized page layout

## 🛠️ Technologies Used

- HTML5
- CSS3
- Responsive Web Design
